Задание 1.
Задача 1(3). Имена.
Текст задачи:
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя,
Отчество. Имя может быть приведено к строковому виду, включающему традиционное
представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван
Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может
быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.
Необходимо создать следующие имена:
• Клеопатра
• Пушкин Александр Сергеевич
• Маяковский Владимир
Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в
образовании строки.

Алгоритм решения:
В классе Name создается 3 конструктора (перегрузка) для случаев, когда в обьекте указано только имя, полное ФИО, или фамилия с именем. Метод toString смотрит, какого поля нет, и возвращает строку.

Задание 2
Задача 1 (2). Человек с именем.
Текст задачи:
Объедините сущности Человек из задачи 1.2 и Имя из задачи 1.3 таким образом, чтобы имя
человека задавалось с использованием сущности 1.3, а не строки.
Необходимо объединить ранее созданные объекты имен и людей, с получением:
• Человека с Именем Клеопатра и ростом 152
• Человека с Именем Пушкин Александр Сергеевичи ростом 167
• Человека с Именем Маяковский Владимир и ростом 189

Алгоритм решения:
класс Human - наследник класса name, в обьект этого класса сначала передается новое поле height, затем существующий обьект класса name. Tostring также наследуется с добавлением роста в конце. 

Задача 2 (3). Человек с родителем.
Текст задачи:
Измените сущность Человек из задачи 2.2 добавив ему возможность задавать третий параметр:
Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо
проверить параметры имени, и в зависимости от ситуации выполнить одно из следующих
действий:
• Если у данного человека нет фамилии, и есть отец, у которого фамилия задана, то
фамилию необходимо сделать такой же как у отца.
• Если у данного человека нет отчества, а у отца есть имя, то необходимо задать отчество
как имя отца с добавлением суффикса “ович”.
Затем необходимо выполнить следующие задачи:
1. Создать людей: Чудова Ивана, Чудова Петра, Бориса
2. Сделать Ивана отцом Петра, а Петра отцом Бориса
3. Вывести на экран строковое представление всех троих людей.

Алгоритм решения:
Создается класс человека с отцом, наследующий класс human, но с полем для отца (в конструкторе сначала человек с ФИО и ростом, затем - еще один человек, который будет отцом для первого.). Tostring проверяет наличие отчества/фамилии, и изменяет их у данного обьекта в соответствии с таковыми у обьекта-отца. Возвращается наследованный tostring (как в прошлом задании, ФИО и рост)

Задание 3
Задача 1 (2). Ломаная
Текст задачи:
Создайте сущность Ломаная, которая будет представлять собой ломаную линию. Ломаная линия представляет собой набор следующих характеристик:
• Имеет массив Точек (из задачи 1.1), через которые линия проходит.
• Может быть приведена к строковой форме вида “Линия [Т1,T2,…,TN]”, где TN – это
результат приведения к строке Точки с номером N
Необходимо выполнить следующие задачи:
• Создать первую Ломаную, проходящую через точки {1;5}, {2;8}, {5;3}
• Создайте вторую Ломаную, чья первая и последняя Точка совпадает с таковыми у первой
Ломаной, но в качестве середины имеет точки: {2,-5}, {4,-8}
• Сдвиньте начало первой Ломаной таким образом, чтобы одновременно сдвинулось
начало второй Ломаной.

Алгоритм решения:
Класс точки для ломаной (Point) возвращает строку с координатами точки вида {x,y}.
Класс Line имеет поле c массивом из точек Point[], этот же массив принимается в конструкторе. Возвращает строковое представление массива из точек. В классе main создается общая первая точка для двух ломаных, затем 2 массива из точек (заполненные по заданию), и наконец два обьекта ломаных, в которые передаются эти массивы.
После вывода обоих ломаных координаты первой точки изменяются, так что она смещается в обоих ломаных.

Задание 4
Задача 1 (9). Создаем ломаную
Текст задачи:
Измените сущность Ломаная из задачи 1.3.2. Новые требования включают:
• Ломаная может быть создана без указания каких-либо параметров
• Ломаная может быть создана с указанием некоторого набора Точек

Алгоритм решения:
Создается еще один класс ломаной, в котором есть поля с строкой - выбранным из перегрузки конструктором и массивом точек. Если создается ломаная без параметров - в tostring возвращается пустой массив. Если создается ломаная с произвольным количеством точек (конструктор с переменным колвом аргументов) - в tostring проверяется значение строки конструктора и возвращается массив из этих точек.

Задание 5
Задача 1(7). Длина ломаной
Текст задачи:
Измените сущность Ломаная из задачи 4.9. Новые требования включают:
• В любой момент к имеющимся Точкам можно добавить новые Точки (добавляется либо
массив, либо просто перечень Точек, что приводит к получению нового массива,
содержащего как старые, так и новые значения).
• Может возвращать общую длину Ломаной.
Необходимо выполнить следующие задачи:
1. Создать Ломаную, проходящую через точки {1;5}, {2;8}, {5;3}
2. Вывести на экран её длину
3. Добавить (к ранее созданной Ломаной) точки {5;15}, {8;10}
4. Снова вывести на экран длину Ломаной

Алгоритм решения:
Создается еще класс ломаной, который теперь может принимать и произвольный набор точек, и массив (так же через varargs). У него создается метод, позволяющий добавить к получившемуся в обьекте класса массиву еще точки, точно так же произвольные/из массива. для этого в методе создается новый массив, по длине равный сумме длин массива уже имеющегося в обьекте, и массива добавляемого. Сразу при создании в него помещаются все точки из уже имеющегося массива (copyOf), а затем точки из добавляемого массива помещаются в него циклом (i=длине старого массива, так что они добавляются сразу после старых точек на пустые места). обновляется ссылка так, что теперь старый массив равен получившемуся. Класс выводит в tostring массив точек и его длину.
